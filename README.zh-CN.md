# Cap 中文本地版

基于 [CapSoftware/Cap](https://github.com/CapSoftware/Cap) 的桌面版本，面向本地录屏、截图、编辑和导出。无需注册、登录或购买订阅。

## 使用

打开安装包，将 `Cap 本地版.app` 拖到“应用程序”，然后打开应用。首次运行按中文提示授予 macOS 屏幕录制和辅助功能权限；麦克风与摄像头按需授权。系统要求时重启应用，然后选择屏幕、窗口或区域开始录制。

- **录制**：使用“工作室”模式，录制结果保存在本机。
- **截图**：支持本地截图、编辑、复制和保存。
- **录制分辨率**：主窗口或“设置 → 常规 → 录制”可选 **720p（1280×720）、1080p（1920×1080）、2K/1440p（2560×1440）、4K（3840×2160）**，默认 4K。此参数直接控制屏幕、窗口及区域采集；保持原比例，竖屏自动交换宽高，低于所选分辨率的画面不会被放大。设置自动保存，下一次录制继续使用。
- **帧率**：同一位置可选 **24、25、30、60、120 帧/秒**，默认 60。该值是采集上限，实际还受屏幕刷新率限制。开启摄像头时最高 30 帧/秒（兼容画质为 24 帧/秒）。纯摄像头录制使用摄像头设备设置中的分辨率和帧率。
- **4K**：选择 4K 档位及原生像素达到 3840×2160 的采集源。录制分辨率与编辑器中的导出分辨率是独立设置。
- **精确尺寸**：修复固定画面比例在中间取整后导致最终尺寸偏差的问题，16:9 的 4K 导出准确采用 3840 × 2160。
- **导出**：新建导出设置默认为 4K、30 帧及本地文件，也可复制到剪贴板。用户已有的画质选择会保留。GIF 仍使用其适用的较低分辨率和帧率。
- **兼容模式**：降低编码码率，但仍使用所选录屏分辨率。

录制的实际帧率取决于采集源、机器性能及同时运行的其他软件。macOS 显示设置中的“看起来像”尺寸不等于录制的实际像素尺寸。

## 本地版行为

- 移除登录页、订阅页、许可证页以及账户和订阅入口。
- 只提供工作室录制与截图，旧的即时云录制偏好会转换为工作室录制。
- 移除分享、上传及云集成入口，并禁用需要账户的云端请求。
- 新的自动化规则只提供本地可用的触发器和动作；旧的云上传动作不再执行。
- 禁用使用情况统计及官方自动更新。
- 使用独立的应用标识 `local.cap.desktop.zh`，与官方版数据分开存放。
- 默认中文界面、菜单、权限说明、编辑器、导出设置、设备选项及常用提示；保留文件格式、快捷键名称、品牌、字体名称和内部协议标识。

改造范围是 `apps/desktop` 的 Tauri 桌面应用；网站、服务端及实验性的 GPUI 应用保留上游源码，不参与本地版打包。开源许可证及原有版权声明保留。

## 从源码构建

需要 Node.js 20 或更新版本、pnpm 10.5.2、仓库指定的 Rust 工具链和 CMake。macOS 还需要 Xcode；Windows 需要上游要求的本机构建工具。

```sh
pnpm install --frozen-lockfile --filter @cap/desktop... --filter cap
pnpm build:local
```

该命令准备媒体依赖、构建本地辅助程序，再使用 `apps/desktop/src-tauri/tauri.local.conf.json` 打包。首次构建需要下载依赖并编译媒体引擎，耗时较长。

macOS 本机包采用临时签名，不依赖开发者账号。跨电脑分发所需的开发者签名与公证尚未配置。不要使用上游生产配置替代本地版配置。
